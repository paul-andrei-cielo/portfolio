  • SDCanteen is a mobile application designed for the canteen of St. Dominic College of Asia (SDCA), aiming to digitize and streamline the canteen transaction process. It seeks to make ordering and purchasing more convenient by reducing reliance on traditional, manual transactions.

    Tech used

    • Android Studio
    • Kotlin
    • Java
    • XML

  • Req-IT is an IoT-enabled document request and tracking system designed for the Registrar’s Office of St. Dominic College of Asia. It allows students and alumni to request academic documents online, track request statuses, and receive notifications. It also provides a registrar portal for managing requests, verifying clearances and payments, and using RFID technology to verify identities during document claiming. The system aims to make the document request process more convenient, efficient, and secure.

    Tech used

    • Dart
    • Node.js
    • Express.js
    • MongoDB
    • Render
    • RFID Reader
    • Bruno

  • MindBlossom is a mood-tracking note-taking app that allows users to write down their thoughts, experiences, and daily reflections. At the end of each note, users can select the emotion that best represents how they feel. These emotions are then displayed on a calendar, allowing users to look back on their entries and track their moods over time. MindBlossom combines journaling and mood tracking in one app, helping users reflect on their feelings and become more aware of their emotional patterns.

    Tech used

    • Android Studio
    • Kotlin
    • Java
    • XML
